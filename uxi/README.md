# UXI — User eXchange Interface

UXI is the adaptable interaction layer of **Sno1 Da Aye Eye**.

It provides the shared environment where the user and AI can:

- communicate and exchange information
- display conversations, explanations, and structured outputs
- use adaptable workspaces and components
- propose, accept, reject, and refine interface changes
- retain agreed interaction preferences

UXI is not limited to an avatar or chat screen. Those are possible components within the wider exchange environment.

UXI must remain declarative, permission-aware, inspectable, and reversible. It must not gain unrestricted execution or system access merely because it can adapt its presentation.
